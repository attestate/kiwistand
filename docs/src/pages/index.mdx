# Kiwi News Docs

[Kiwi News](https://news.kiwistand.com) is a community-curated news site for
crypto, Ethereum and builder-focused tech, similar to Hacker News: its readers
submit, upvote and discuss links.

Kiwi News keeps its links, upvotes and comments on the protocol level. Each
one is a message signed by an Ethereum key, and the nodes that run Kiwi News
share them over a peer-to-peer network. They aren't transactions on a
blockchain, so posting costs no gas, and anyone can read all of them and build
their own app on top. Only [delegations](/delegation) are onchain.

[kiwistand](https://github.com/attestate/kiwistand) is that node: a p2p node
client for a web3 writer friendly Hacker News that nobody controls but
everybody co-owns. These docs describe the Kiwi News Protocol that kiwistand
nodes speak and the node's HTTP API.
