# Kiwi News Docs

[kiwistand](https://github.com/attestate/kiwistand) is a p2p node client for a
web3 writer friendly Hacker News that nobody controls but everybody co-owns.
It runs [Kiwi News](https://news.kiwistand.com).

These docs describe the Kiwi News Protocol that kiwistand nodes speak and the
node's HTTP API.
